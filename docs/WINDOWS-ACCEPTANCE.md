# Windows 实机验收门禁

macOS 上的语法检查、单元测试和依赖安装只能证明跨平台纯逻辑与静态结构可用，不能证明 Windows 截图和 DPAPI 已真实工作。发布 Windows 第一阶段前，需在 Windows 10/11 x64 实机完成下列检查并保留结果。

## 构建门禁

- [ ] 在全新 Windows 工作目录执行 `npm ci`。
- [ ] `npm run check` 全部通过。
- [ ] `npm run dist:win` 生成 NSIS 安装包。
- [ ] 安装、开始菜单启动、卸载均成功；安装包如对外分发，应完成代码签名与 SmartScreen 评估。

## 核心用户路径

- [ ] 首次启动显示中文未配置状态，截图与选图按钮不可用。
- [ ] HTTPS 端点、模型和 Key 保存后显示“已就绪”；远程 HTTP 地址被拒绝，本机 HTTP 被允许。
- [ ] Key 不出现在 `%APPDATA%` 下的 `settings.json`；`credentials.bin` 不是明文，重启后仍可调用。
- [ ] 更换端点但不输入新 Key 后回到未配置状态，旧 Key 不会发往新端点。
- [ ] 点击刷新后可区分桌面和普通窗口；选择一个目标只产生一次显式截图动作。
- [ ] 截图先显示本地预览；未勾选确认时不能发送。
- [ ] 确认文案显示正确的模型服务域名；确认后出现处理中状态，成功后显示中文建议。
- [ ] 手动 PNG、JPEG、WebP 可预览；伪装扩展名、SVG、空文件和大于 20 MB 文件被拒绝。
- [ ] 无 Key、网络断开、401/429/500、超时、目标窗口关闭和空画面均有可理解的中文错误反馈。

## 游戏与显示环境

- [ ] 在至少一个窗口化/无边框游戏中验证所选窗口截图内容和尺寸。
- [ ] 在多显示器、125%/150% DPI 下分别验证桌面来源与预览。
- [ ] 验证全屏独占或受保护画面失败时只报错，不尝试规避保护。
- [ ] 连续观察任务管理器和网络活动：没有后台周期截图，没有未确认上传。
- [ ] 验证应用没有发送鼠标、键盘或手柄输入，没有游戏进程注入或内存读取。

## 当前结论模板

验收报告应明确写成以下两类之一：

- `跨平台/静态验证通过；Windows 实机验收尚未完成`；或
- `Windows 实机验收通过`，并附 Windows 版本、应用版本、测试游戏/窗口模式、构建命令和检查日期。
